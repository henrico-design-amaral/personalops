# PersonalTrainerOPS — Accessibility Contract

Status: ACTIVE
Version: 1.0
Date: 2026-09-01
Authority: HenricoOPS A11Y Gate + current product journeys

## Baseline
All user-facing PersonalTrainerOPS interfaces target WCAG 2.2 AA.

## Required
- semantic landmarks/headings;
- keyboard-complete controls on web surfaces;
- visible focus;
- sufficient contrast;
- meaningful form labels, validation and error states;
- touch-friendly student/training controls;
- color not used as sole carrier of training/status meaning;
- zoom/reflow without destructive overflow;
- reduced-motion support;
- accessible timers/progress/status updates;
- meaningful alternative text/media treatment;
- readable loading/offline/sync/error states.

## Role/journey emphasis
- Professor: student management, training creation/prescription, monitoring and financial-operation screens.
- Student: authentication, training week, assisted execution, timer, logging and feedback.
- Admin: platform operations without assuming student-management responsibility.

## Exercise/training content
Visual exercise media must not be the only source of essential instruction when accessible textual support is required.

No local exception weakening this baseline is approved by this file.
