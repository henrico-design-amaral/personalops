# Foundation brief

- **Produto:** PersonalOps
- **Alias:** `PersonalOps`
- **Direção:** clareza operacional pessoal, não gestão genérica de tarefas
- **Stack:** Astro, TypeScript estrito, Preact isolado, Supabase, CSS por tokens
- **Produção:** `https://personalops.henrico.works` via GitHub Actions e Hostinger

## Princípios

- Estrutura, regras e relações são o produto; a interface é consequência.
- Energia e capacidade alteram a leitura do dia.
- Métricas precisam apoiar decisão, não decorar dashboard.
- Estados vazios devem orientar uma ação real.
- Nenhuma ação pode simular persistência.
- Build verde é um gate, não a conclusão.

## Identidade

Editorial Light `#F3F0EA`, Operational Dark `#151313`, Structure Light `#D8D2C9`, Structure Dark `#282321`, Ink `#1A1715` e Signature Gold `#FFC83D`. Inter sustenta leitura e Syne assina hierarquia. A proporção visual de referência é 60/30/10, com motion discreto e funcional.
