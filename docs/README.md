# Mapa da documentação atual

- `architecture/`: estrutura da aplicação e fronteiras.
- `data/`: modelo relacional, RLS, migrations e seed.
- `deployment/`: GitHub Actions e Hostinger.
- `diagnostics/`: inventário anterior à reconstrução.
- `migration/`: classificação e destino do produto anterior.
- `operations/`: ambiente local e comandos.
- `qa/`: gates e evidências de validação.
- `execution/`: relatório datado de release, criado após a validação de produção.

Documentação fitness histórica está em `legacy/fitness-prototype/docs`.
